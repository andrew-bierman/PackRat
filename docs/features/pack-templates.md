# Pack templates

Ready-made gear lists a user can start a pack from, or add to a pack they
already have, instead of building every list from scratch.

## The model in one paragraph

A template is a gear list that isn't tied to a trip. Some are **Official**:
lists put together by experienced hikers and reviewed by the PackRat team
before anyone sees them. The rest are the user's own, saved for the kinds of
trips they repeat. Neither kind is ever packed itself. Applying a template
copies its items into a pack, either a new one or one the user already has.
After that the pack belongs to the user and changing it never touches the
template, and changing the template never touches packs made from it.

## Browsing templates

The Pack Templates screen has two parts.

- **Official** sits at the top as a shelf: columns of three templates that
  scroll sideways, with the edge of the next column showing so it reads as
  scrollable. Each row shows the template's cover image (or an icon for its
  category), its name with a verified badge, and its item count, total weight
  and category. Tapping the **Official** heading, under which it says "Ready-made
  gear lists from experienced hikers", opens the full list of official
  templates.
- **My Templates** follows, listing the user's own templates. With none yet,
  it invites the user to save a list they reuse or start from an official one,
  with a **New Template** button.

Searching drops the shelf and shows matching templates as flat results,
grouped under Official and My Templates.

Templates need an account. A signed-out user sees what templates are for and
is invited to sign in. Building packs by hand works without one.

## A template's details

Opening a template shows its description, an **Official** badge if it is
one, its category, its item count and total weight, a chart of where that
weight goes by category, and the gear list grouped by category. Each item
shows its weight and quantity, and whether it is worn or consumable.

Official templates are read-only. The user's own templates can be edited
there: rename, change the description and category, add, edit and remove
items.

## Applying a template

**Apply to Pack** opens a sheet with **New Pack** first and the user's
existing packs below it, each with its item count.

- **New Pack** asks for a name, prefilled with the template's name, then
  creates the pack with the template's description and category and every
  item in it.
- **An existing pack** gets every item from the template added to it. Items
  already in the pack stay as they are.

The whole template is copied in one step, so even a long list lands in a
few seconds. While it copies, the chosen row shows "Adding N items…" and the
sheet can't be closed. When it finishes, the user lands in the pack they just
filled. That pack is the confirmation.

If the pack is created but its items can't be added, the sheet comes back
with the new pack at the top of the list, so one tap retries without making
a second pack. Applying needs a connection.

## Making a template

**New Template** creates one from a name, description and category. Items are
added from the template itself.

## What this feature does not do

- Users don't publish templates. Only the PackRat team adds Official ones.
- Applying a template doesn't merge duplicates. An item already in the pack
  is added again.
- Applying a template doesn't work offline.
- Packs made from a template don't follow later changes to it.
